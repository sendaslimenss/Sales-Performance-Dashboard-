## Objective

The objective of Week 2 was to prepare the SQL layer and connect Grafana to the PostgreSQL database.

## Completed Tasks

- PostgreSQL database prepared and validated.
- Sales data loaded into the `sales` table.
- Data validation and sanity checks performed.

The following SQL queries were implemented and tested:

1. Total Revenue
2. Total Orders
3. Average Order Value
4. Monthly Revenue
5. Top 5 Product Categories
6. Revenue by Region
7. Month-over-Month Growth

### Grafana Setup

- Grafana was connected to the PostgreSQL database.
- The PostgreSQL data source was configured successfully.
- SQL queries were tested in Grafana.

Grafana successfully retrieves the required sales data from PostgreSQL using SQL queries.
